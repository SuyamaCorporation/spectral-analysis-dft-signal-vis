# 離散フーリエ変換DFT信号スペクトル分析ビジュアライザー

正弦波成分を重ね合わせた入力信号をDFT（高速フーリエ変換・Cooley-Tukey FFT実装）で解析し、時間領域波形・振幅スペクトル・位相スペクトルをCanvas上にリアルタイム表示するツール。
方形波・三角波・ノコギリ波・ホワイトノイズのプリセットも収録。各成分の周波数・振幅・位相をスライダーで自由に調整可能。
スペクトルの主要ピーク周波数を自動検出して表示する。サンプル数は64/128/256/512から選択可能。

## 使い方

1. プリセットボタンで波形を選択するか、「+成分を追加」で正弦波成分をカスタム設定する
2. 各成分の周波数・振幅・位相スライダーを動かすとリアルタイムにスペクトルが更新される
3. サンプル数を変更すると周波数分解能が変化する（大きいほど細かい）
